# GharMoolya web

React frontend for the GharMoolya valuation prototype (Vite, TypeScript, Tailwind CSS, react-router, recharts, Leaflet).

| Route | Page | Data |
|---|---|---|
| `/dashboard` | Executive overview | `metrics.json`, `queue.json`, `cities.json` |
| `/evaluate` | New valuation | `form_localities.json`, `amenities.json`, live `POST /valuate` |
| `/report/:id` | Report and explainability | A stored live response, or `valuations.json` |
| `/market-explorer` | Micro-market explorer | `listings.json`, `localities.json`, `metrics.json` |
| `/model-audit` | Governance and data sources | `metrics.json` |

All files in `public/data/` are generated by `prototype/scripts/export_web_data.py` and committed, so the build needs no Python. Rates are listing asking prices from a 2020 snapshot, not transactions.

## Develop

```bash
npm install
cp .env.example .env.local   # VITE_API_URL, default http://localhost:8000
npm run dev
npm run lint
npm run build
```

The evaluate page needs the API running (`uvicorn src.api:app --port 8000` in `prototype/`). If it is unreachable the page says so and shows no estimate. A sleeping Render service is polled on `/health` for up to 90 seconds and the request is retried once.

## Regenerate the data

From `prototype/`: `python -m scripts.export_web_data`. It needs the trained engine and the prototype dependencies.

## Deploy on Vercel

- Root Directory: `web`
- Build command: `npm run build`
- Output directory: `dist`
- Environment variable: `VITE_API_URL` set to the Render service URL (no trailing slash)

`vercel.json` rewrites all other paths to `index.html` for client-side routing. The API must list the frontend origin in its `ALLOWED_ORIGINS` environment variable.
