# GharMoolya

An explainable property valuation engine for Indian home loans. Built by **Neural Knights** (Shashank, Yatin Allan S, Nimit Jain) for the Hero Housing Fintech Challenge, Problem Statement 1: AI-powered digital property valuation engine.

Live prototype: [ihack.shashankbindal.me](https://ihack.shashankbindal.me)

For each property, the engine returns:
- a value
- a calibrated 80% range
- an A–D confidence grade
- the factors that move the value
- nearby comparables
- a routing decision: auto-accept, desktop review or physical valuation

The routing respects the RBI Housing Finance Company Directions, 2025: tiered LTV caps, and two valuer reports for loans of Rs 75 lakh and above.

## Headline results

The prototype covers 4 cities and 4,361 listings, scored on held-out H3 cells, i.e. neighbourhoods the model never saw.

| Metric | Result |
|---|---|
| Median absolute error, our model | 15.3% |
| Median absolute error, city-median baseline | 21.6% |
| 80% interval coverage | 78.9% |
| p95 API latency | 119 ms |

The errors are measured against listing **asking prices**, a proxy for transaction values. See `prototype/README.md` for the full caveats and for the work that was not run.

## Run it

```bash
cd prototype
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m streamlit run app/streamlit_app.py
.venv/Scripts/python -m uvicorn src.api:app --port 8000
```

The trained engine (`models/engine.joblib`) and the processed features are committed, so the app and API run without the 750 MB OpenStreetMap download. To reproduce everything from raw data, run `run_all.py`.
